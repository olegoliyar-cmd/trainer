## ЧАСТИНА 1. КЛІЄНТСЬКИЙ АПП (проходимо перші)

Екрани по порядку нижньої навігації + вкладені:
1. **Сьогодні (хаб)** — привітання, «Твій тиждень», картка програми, **картка звіту**
   (незаповнений = заклик; заповнений = «✅ Звіт за сьогодні заповнений · 80%»),
   **картка «Найближча зустріч»** (кнопки підтвердження / «Приєднатися»), стрічка тижня
   (⚠️ виконані дні мають виглядати ОДНАКОВО — фіксили колізію класу `today`), швидкі плитки.
2. **Програма** — місяці/тижні, дні A/B/C, старт тренування, екран вправи (відео, підходи),
   кнопка «📹 Відео тренеру».
3. **Прогрес** — графіки, «Заміри та фото»: список точок («📷 2/4») → **екран точки**
   (параметри + 4 слоти ракурсів) → фото у **повній якості** + **⤓ завантажити**;
   «Побачити різницю» (дельти + «Фото · було → стало»).
4. **Харчування** — денний баланс, додавання прийому: пошук / **📷 фото (AI)** / **🎤 голос (AI)**,
   екран перегляду розпізнаного, деталі прийому.
5. **Чат** — вкладка «Тренер» = кнопка **«💬 Чат з тренером»** (веде в Telegram);
   вкладка **«Розбори»** = список → екран розбору (відео, галерея скрінів, зум, голосові, текст).
6. **Звіт-квіз** — вхід із хабу або з TG-кнопки (deep-link `?screen=report`); один тап на питання,
   фінал: %, «5 з 6 виконано», кнопка **по центру**.
7. **Профіль/налаштування** — що лишилось зайвого після чисток (спільнота/рейтинги вже прибрані).

**Дивитись окремо:** safe-area (нічого не лізе під кнопки Telegram), однакові відступи,
чи немає мертвих кнопок «Незабаром».

6. **Календар** — ⚠️ на мобільному він у **бургер-меню (☰)**; всередині «+ Зустріч».
